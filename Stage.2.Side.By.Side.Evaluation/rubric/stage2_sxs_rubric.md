# Stage 2 SxS Rubric

**Grounding:** Are personalized claims supported by supplied user evidence?
**Integration:** Is personal information naturally and appropriately woven into the answer?
**Helpfulness:** Does personalization improve usefulness?
**Personalization Relevance:** Is the selected context relevant to the request?

**Forced personalization:** Personal context is used mainly because it is available rather than because it helps.
**Unsupported inference:** The response infers a preference, trait, intention, habit, or fact not supported by evidence.

**SxS:** Choose A, B, or Tie. Do not choose based on amount of personalization.

**Rationale:** 2–4 sentences. State the behavior, cite context IDs, explain the impact, and compare the responses.
