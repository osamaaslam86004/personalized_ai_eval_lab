# Stage 2 — SxS Evaluation Rules

1. Read context and request before comparing A/B.
2. Score A and B independently on Grounding, Integration, Helpfulness, and Personalization Relevance, each 1–5.
3. Mark Forced and Unsupported separately.
4. Select A, B, or Tie.
5. Write a 2–4 sentence evidence-based rationale.
6. Do not invent additional user facts.
7. More personalization is not automatically better.
8. Missing personalization is not automatically a defect.
9. Keep Grounding, Integration, Helpfulness, and Relevance distinct.
10. Complete all cases before consulting any gold notes.
